rclone-backup

rclone-backup is a personal backup setup used by the GitHub user Wwaste. It runs rclone on the owner's own computer to copy the owner's own files to the owner's own Google Drive.

It is not a public service and is not offered to anyone else.

rclone-backup 是 GitHub 用户 Wwaste 自用的备份工具：在本人电脑上用 rclone 把本人的文件备份到本人的 Google Drive，不对外提供服务。
